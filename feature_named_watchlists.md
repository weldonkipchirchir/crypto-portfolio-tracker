Named watchlists are private to the authenticated account. Up to 20 lists and 100 exact CoinGecko IDs per list. The catalog is the existing top 500 listings snapshot, not symbol matching. Load listings before adding a coin; actions use cached catalog data and never make network requests. Notes are plain text, up to 2000 characters. Deleting a list or removing a coin explicitly confirms permanent removal of its notes. Optional columns use USD snapshot market data; missing values remain unavailable and stale feed state is displayed. No sharing endpoints.
